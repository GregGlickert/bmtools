# Spike Plotting API

This module provides functions for creating various visualizations of neural spike data, including raster plots and firing rate distributions.

::: bmtool.bmplot.spikes.raster
    options:
      show_root_heading: true
      heading_level: 3

::: bmtool.bmplot.spikes.plot_firing_rate_pop_stats
    options:
      show_root_heading: true
      heading_level: 3

::: bmtool.bmplot.spikes.plot_firing_rate_distribution
    options:
      show_root_heading: true
      heading_level: 3
